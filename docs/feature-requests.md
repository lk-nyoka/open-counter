# Feature requests

For the optional Devpost field: what we'd want built, why it matters, and how urgent it is.

| Request | For | Why it matters | Urgency |
|---|---|---|---|
| A card-free, time-boxed developer path to deploy MCP add-ons (public npm CLI, no AWS account for the development stage) | Alexa+ | Today the Alexa+ path is closed to students and builders outside the US without a card, exactly the people building for small local businesses | Critical |
| Make the MCP Toolkit and web simulator available outside the US for development | Alexa+ | Builders in other countries can't test what they build, even if their customers will be in the US first | Critical |
| One requirements checklist page with rule IDs (latency p50/p99 and region, response size, auth, accessibility) | Alexa+ | Builders can design to the rules from day one instead of discovering them late | Important |
| A per-add-on vocabulary hint for speech recognition (business and service names) | Alexa+ | Names like "Corner Cuts" or a stylist's name are the most misheard words in a booking | Important |
| State the supported MCP Apps version and metadata key, with a raw-protocol example | Alexa+ / MCP Apps | Teams without a bundler can ship cards confidently | Important |
| A server option to require a minimum MCP protocol version | MCP TypeScript SDK | Silent down-negotiation hides client bugs | Nice to have |
| Validate the model id when an agent is created, and list available models on error | Strands Agents | Retired model ids fail mid-conversation today | Nice to have |
| A "human approval for a tool" cookbook recipe | Strands Agents | The hook pattern is powerful but not obvious | Nice to have |
| One-off Kiro credits for registered hackathon participants | Kiro | The free tier can run out before a challenge that asks for Kiro | Important |
