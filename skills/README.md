# Agent Skills

`open-counter-booking/` teaches any agent that supports Agent Skills (Claude Code, Kiro, Cursor, VS Code Copilot and others) how to book through Open Counter's MCP server safely: find the business, offer only real times, read back, wait for a yes, book once with an idempotency key, and handle each refusal.

Install by copying the folder into your agent's skills directory (for Claude Code: `~/.claude/skills/`).
